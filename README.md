# Парсер мероприятий
### Описание
Этот проект собирает данные о предстоящих и прошедних мероприятиях города (на оригинальном сайте старые мероприятия исчезают и не ведется история).
Спарсеные данные добавляются в базу sqlite через SQLAlchemy
необходимо запустить Flask run app.py и открыть http://127.0.0.1:5000/

### Установка

pip install -r requirements.txt
